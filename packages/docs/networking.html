Caveats

No remote service may be presented as supported before isolation, hostile fuzzing and a proven userland TLS. DMAR detection is not DMA isolation: a DMA-capable device needs IOMMU tables, domains, invalidations and translation enable observed.

Documentation reflects observed state; see the repository for the authoritative records.
