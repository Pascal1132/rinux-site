Run Rinux in VirtualBox or VMware

A diskless VM kit built by CI: the ISO is attached as a CD and everything runs from memory.

Quick start

  1. Download rinux-vm-kit.zip from the home page and unzip it.
  2. VirtualBox: run rinux-virtualbox.bat (Linux/macOS: sh rinux-virtualbox.sh). It creates a VM named Rinux dev build and starts it.
  3. VMware: open Rinux.vmx and power on.
  4. Wait a few seconds for the rxsh> prompt, click in the window and type help.

A completely black screen means the boot did not reach the console. Earlier development ISOs (the R0 profile) owned a serial-only console and looked exactly like that in a VM window.

What is in the kit

FilePurpose
rinux.isoThe development ISO (BIOS/UEFI hybrid, Limine).
Rinux.vmxVMware definition: 512 MB, 1 CPU, BIOS, CD only, no network, no USB.
rinux-virtualbox.bat / .shCreates the VirtualBox VM through VBoxManage (ICH9 chipset, I/O APIC, PS/2 keyboard and mouse).
SHA256SUMSChecksum of the ISO.

Why there is no VMDK or VDI disk

VirtualBox / VMwareIDE, SATA, NVMe, LSI…
Rinux driversVirtIO block only
Resulta virtual disk could not be read

Rinux has no AHCI, IDE, NVMe or LSI driver, so a disk image would be unusable. The system boots from the CD into an in-memory root; nothing persists.

What was verified

  • Kernel boots in VirtualBox 7.2 (ICH9, BIOS): framebuffer 1024x768 found, PS/2 input fallback, on-screen shell, typed commands answered.
  • Kernel boots in VMware Player from the shipped .vmx: framebuffer found, console owner fbtty (checked through the serial log; the VMware screen itself was not captured).
  • CI boots the exact packaged ISO under QEMU q35 and checks the console markers before publishing.

Not verified: UEFI firmware in either hypervisor, macOS/Fusion, the Linux/macOS VirtualBox script (syntax-checked only), and any hardware other than these. The ICH9 and 1024x768 settings match what the project tests under QEMU q35.

Not included

  • The graphical desktop: startgui needs a different console profile and the GUI gates are currently regressed.
  • Networking, audio, USB and persistent storage.
