Rinux documentation

How each part of the Rinux kernel and userland works, with diagrams. Every page states what is implemented, what is a prototype and what is still open.

Parts of the system

OverviewRinux is a monolithic x86_64 kernel written in Rust, booted by Limine, with a statically assembled Ring 3 userland.BootFrom Limine handoff to PID 1.MemoryFrame allocator, kernel heap, four-level page tables, VMAs, copy-on-write fork and TLB shootdown — with SMAP-guarded user copies.SchedulerPer-CPU runqueues, idle tasks, migration and affinity — but the product default runs a single CPU.SyscallsA Linux-like subset.VFS & storageOne VFS in front of in-memory, pseudo and on-disk filesystems, backed by a VirtIO block driver.NetworkingA feature-gated in-kernel stack.GUIA diagnostic prototype today; a separated session / compositor / client design is the target.Run in a VMA diskless VM kit built by CI: the ISO is attached as a CD and everything runs from memory.EngineeringRinux is run as an evidence-driven project: a claim is only as strong as a reproducible gate on a clean commit.
