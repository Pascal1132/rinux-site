Process, signals and events

Processes, threads, fork/COW, exec, signals, futexes, waits and descriptors exist. poll, epoll, eventfd, timerfd and signalfd are present but partial; the epoll_event ABI, subscription lifetime and HUP/ERR handling are active findings. Epoll objects are still tied to FD numbers rather than open file descriptions.

Documentation reflects observed state; see the repository for the authoritative records.
