Architecture overview

Rinux is a monolithic x86_64 kernel written in Rust, booted by Limine, with a statically assembled Ring 3 userland. It targets a subset of the Linux syscall ABI, not full Linux compatibility.

The kernel keeps scheduling, address spaces, VFS, syscalls, current network protocols and drivers. The GUI composes in userland but still opens /dev/fb0 and /dev/input/* directly in the prototype profile.

Why “monolithic”, and where the microkernel idea stands

All drivers, the VFS and the network stack run in Ring 0. Several ADRs (015–020) describe a target in which policy moves to userland — a non-root compositor, a session manager, userspace drivers — but those are proposed, not delivered.

Earlier versions of this site called Rinux a “microkernel”. That overstated the current design, so the wording was corrected.
