Desktop and GUI

A diagnostic prototype today; a separated session / compositor / client design is the target.

Current prototype

Single session, single seat, auth=none, privileged direct access to scanout and input. Buffers are named files /tmp/rinux-display-buffer-<id> opened by path.

Kernel provides mechanism only; window placement, focus, clipboard and reconnect are userland policy (ADR-015).

Wire protocol

Display/input constants and codecs are generated from abi/display_input.tsv into both kernel and userland Rust, so the two sides cannot drift.

Not claimed

Multi-client, multi-user, credential isolation, Wayland compatibility, crash-recoverable sessions. Run it with just run-gui (SDL on Windows); QEMU GTK is diagnostics only because its input grab is unsupported after host focus changes (DEFECT-007).
