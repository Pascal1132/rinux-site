Fallible allocation

Kernel code uses fallible allocation helpers (ADR-004) so a hostile or exhausted state returns an error instead of aborting. Correctness-critical paths must not ignore these results.

Known open items

  • NMI / GS / CR3 and PCID-KPTI contexts still to be qualified.
  • IOMMU is not enabled; DMAR detection is not DMA isolation.
  • The userland framebuffer mapping does not yet use the same cache type as the kernel alias.
  • Fork/COW under SMP: DEFECT-219 is under investigation.
