Zombie and scheduler queues use intrusive lists (ADR-008).

Locking discipline

Locks go through lockdep-checked wrappers. Project rules additionally forbid allocation, sleeping, usercopy or I/O waits while holding a spinlock or with interrupts disabled.

Known violations being tracked: some I/O under the FD-table spinlock, an incorrect SRCU interleaving, and waits implemented by polling or busy-spin.

Read-mostly data uses RCU (ADR-011); scalability work uses per-CPU structures (ADR-012).
