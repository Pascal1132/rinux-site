Rinux

An experimental x86_64 kernel written in Rust — no_std, higher-half, built from scratch.

Download ISO Read the docs

What it is — and isn’t

Rinux is a research platform for memory isolation, SMP, storage recovery and a userspace desktop. It is a monolithic kernel with a Ring 3 userland and a Linux-like syscall subset.

It is not production-ready, not a daily driver and not a Linux-compatible general-purpose OS. Every claim here is bound to reproducible evidence; open defects are tracked publicly.

Try it in VirtualBox or VMware

A ready-made VM kit: no install, no disk. Rinux runs from memory and nothing is saved.

Download VM kit (.zip)

The VM kit appears here once a development build is published.

  1. Unzip the kit.
  2. VirtualBox: double-click rinux-virtualbox.bat (Linux/macOS: sh rinux-virtualbox.sh).
  3. VMware: open Rinux.vmx and power on.
  4. After a few seconds you get a text console with an rxsh> prompt. Click in the window and type help.
  5. Optional: type startgui for the prototype graphical desktop (it stays until you reboot the VM).

Why no VMDK/VDI disk? Rinux only has a VirtIO disk driver, which neither hypervisor offers. The kit was booted in VirtualBox 7.2 and VMware Player; the desktop (startgui) was checked in VirtualBox only. Details.

Boot in QEMU

qemu-system-x86_64 -m 512M -cdrom rinux-latest.iso -serial stdio

Build from source

git clone https://github.com/Pascal1132/Rinux.git
cd Rinux
just check        # lint, ABI and policy checks, unit tests
just run-minimal  # boot in QEMU
just run-gui      # development GUI (SDL)
